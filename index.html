El problema

Muchas interfaces obligan a entender el sistema antes de poder hacer la tarea.

Navegación, banners, beneficios, formularios, mensajes y decisiones aparecen al mismo tiempo. Para una persona con dificultades de atención, memoria de trabajo o comprensión, esa complejidad puede convertirse en una barrera.

NavegaClaro invierte la relación: primero entiende el objetivo; después reduce el recorrido a lo indispensable.

Por qué no es un wrapper

La IA decide sobre controles verificables.

El LLM no recibe libertad para inventar selectores. NavegaClaro construye un conjunto cerrado de elementos válidos y rechaza cualquier salida que se salga de ese conjunto.

  1. 01
    Captura segura

    Extrae estructura visible e interactiva; descarta valores de formularios y campos sensibles.

  2. 02
    IDs controlados

    La extensión identifica controles antes de llamar al modelo.

  3. 03
    IA estructurada

    Groq GPT-OSS 120B devuelve un JSON Schema estricto con un recorrido mínimo.

  4. 04
    Validación

    El backend rechaza targets inexistentes y usa fallback si la respuesta no es segura.

  5. 05
    Guía humana

    El navegador resalta el control real y mantiene a la persona al mando de cada acción.
